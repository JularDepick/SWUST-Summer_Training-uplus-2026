# 实验三：数据结构综合设计

# 实验环境

- 开发环境：Qt Creator + Qt 6.11.1
- 工具链：MinGW 13.1.0(g++ 13.1.0) + CMake 3.30.5
- 技术栈：Qt 6 Quick/QML + Qt Multimedia + Qt Network + Qt Widgets
- 多媒体后端：Qt 随附的 FFmpeg 9.0.1
- 音频标签库：随源码携带并静态链接的 TagLib 2.3.2

其余未提及的项参见 [项目主README #实验环境](../../README.md#实验环境)
