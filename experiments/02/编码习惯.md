# 代码风格规范

## 1. 头文件与命名空间
- 使用 `#pragma once`
- `indexGraph.hpp` 中保留 `#include <bits/stdc++.h>` + `using namespace std;`
- 其他文件只 include 所需 Qt 头，不 `using namespace std;`

## 2. 缩进与换行
- 4 空格缩进
- 短语句用逗号一行: `n=0,m=0,max_id=0,nege_flag=0;`
- `private:` / `public:` 独占一行，下接变量声明，无空行

## 3. 花括号规则
- K&R 风格: `if(condition) {` / `void func() {`
- `} else {` 同行
- 单行语句也必须用花括号

## 4. 圆括号与空格
- 控制关键字后无空格: `if(`, `for(`, `while(`
- `)` 与 `{` 之间有空格: `) {`
- 赋值/比较/算术运算符两侧无空格: `a=0`, `a<b`, `a+b`
- 指针 `Type* p`，取地址 `&var`
- 复杂表达式用 `()` 包裹: `if((!valid))`, `return (n==0);`

## 5. 注释风格（精简原则）

### 原则：注释只说代码没说的事

```cpp
/* 好：解释 WHY */
if(nodes.empty()) {              /* 空图时不执行力导向，避免除零 */

/* 差：重复 WHAT */
_usdint_ n;                      /* 结点数量 */       // ← 变量名已说清
```

### 段分隔符

```cpp
/* ==== GraphDocument ==== */

/* ─── 构造/析构 ─── */

/* ═══ 服务层 ═══ */
```
- 用 `=` / `-` 做层次区分，不写长标题
- 不超过 40 字符宽

### 信号注释

```cpp
signals:
    void graphChanged();         /* 结构变更 */
    void layoutChanged();        /* 位置变更 */
```

### 类注释

不写长描述，一行说明职责：

```cpp
class GraphCanvas : public QGraphicsView {
    /* 画布: 渲染+交互+事件转发, 不操作 indexGraph */
```

### 节注释位置

类内方法分节时，节注释写在 `private:` 之上：

```cpp
private:
    /* 渲染 */
    void rebuildScene();

    /* 事件 */
    void mousePressEvent(...);
```

## 6. 禁止的注释模式

| ❌ 禁止 | ✅ 改为 |
|---------|--------|
| `// 这是一个循环，遍历所有结点` | 什么也不写 |
| `/* 获取结点数量 */ _usdint_ nc = ...` | 代码本身已说清 |
| `====================华丽分割线====================` | `/* ==== */` |
| 每函数都写 `@brief @param @return` | 只在算法复杂处写 |
| 注释中间空行 `/* ... \n\n ... */` | 连续写，不空行 |

## 7. 代码结构习惯
- 成员函数返回引用支持链式: `ClassName& method() { return *this; }`
- 使用 C++11 范围 for: `for(Type var : container) {`
- 循环变量声明在 for 内部
- 错误处理提前返回
- 初始化列表 `={}`: `vector<int> v={};`
- `std::atomic<bool>` 用于全局开关
- `Q_OBJECT` 宏在类声明第一行
