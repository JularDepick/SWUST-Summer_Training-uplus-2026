# Graph-Visual 操作教程

## 基础操作

### 文件管理
- **新建** Ctrl+N：创建空白图
- **打开** Ctrl+O：加载 .indexgraph.json 文件
- **保存** Ctrl+S：保存当前图（自动压缩 JSON 空白符）
- **另存为** Ctrl+Shift+S：保存到新路径
- **重命名** Ctrl+Shift+N：修改图名称
- **关闭** Ctrl+W：关闭当前标签页

### 画布操作
- **缩放** Ctrl+滚轮
- **平移** 中键拖拽 / WASD 键（带加速度）
- **追踪回图中心** Ctrl+Shift+T / 双击缩略图
- **全屏** F11

### 结点操作
- **新增结点** Ctrl+Q / 右键空白处选"新增结点"
- **删除结点** 选中后 Ctrl+D / 右键菜单"删除"（删除全部选中元素）
- **移动结点** 按 M 键进入移动模式，左键拖拽结点，再按 M 退出
- **设置起点** 右键结点选"设为起点"
- **设置终点** 右键结点选"设为终点"
- **切换相邻结点** 选中一个结点后按 . 或 , 循环切换

### 边操作
- **创建边** Shift+左键从源结点拖拽到目标结点
- **创建双向边** 按住 Z + Shift+左键拖拽
- **删除边** 选中后 Ctrl+D / 右键菜单"删除"（删除全部选中元素）
- **编辑边权重** 右键边选"编辑边权重"

### 选择操作
- **单选** 左键点击结点或边
- **多选** Ctrl+左键点击
- **选中连通分量** Ctrl+A（需先选中一个结点或边）
- **全选** Ctrl+Shift+A
- **取消选择** 双击空白处

### 批量操作
菜单栏[批量操作]：
- **选中连通分量**：选中与当前选中元素相连的所有结点
- **全选图**：选中所有结点和边
- **清空图**：删除所有内容
- **清空边**：仅删除边，保留结点
- **重排序修复**：结点 ID 重排为连续值，保持已有布局位置
- **补全为完全图**：对每对未连通的结点补双向边（权重=1）

## 算法演示

### 前置条件
- **DFS/BFS**：选中唯一一个结点作为起点
- **Dijkstra/Bellman-Ford**：先设定起点和终点（右键结点右键菜单）

### 动画流程

| 算法 | 探索过程 | 结束时 |
|------|---------|--------|
| **DFS** | 每次前进高亮新结点，回溯时逐步回退并淡出边 | 保留最终探索状态，Enter/双击恢复 |
| **BFS** | 逐层展开，同步高亮层内结点与发现边 | 保留最终状态，Enter/双击恢复 |
| **Dijkstra** | 最短路径树生长，用前驱边连接已确定结点 | 绿色结点+蓝边展示最优路径，Enter/双击恢复 |
| **Bellman-Ford** | 逐轮松弛，高亮每轮距离改进的结点和边 | 绿色结点+蓝边展示最优路径，Enter/双击恢复 |

### 操作
- 通过菜单栏[算法演示]选择算法
- **暂停/继续** Space 键
- **恢复** Enter 键 或 双击空白处
- 演示中访问过的结点变浅红，当前步变红，最终路径蓝色

## 检查功能

菜单栏[检查]：

| 选项 | 说明 |
|------|------|
| 检查图结构合法性 | 检测缺失结点和无效边引用 |
| 检测自环 | 找出自环边 |
| 检测环 | DFS 检测有向环 |
| 检测孤立结点 | 无入边且无出边的结点 |
| 检测可达性 | 选中两个结点，检测双向/单向可达性 |

## 性能设置

菜单栏[性能]：
- **物理计算帧率**：控制力导向计算频率（默认120FPS）
- **画面渲染帧率**：控制画面更新频率（默认30FPS，不能超过物理帧率）

## 物理模拟

- Tab 键暂停/恢复物理模拟
- 1号结点是锚点，不受物理力影响，不可删除
- **各连通分量独立力导向排布**：多结点分量内部边弹簧力保持结构
- **分量向心力**：各分量内部弱向心引力防止漂移，不同分量不互相吸引
- **孤立结点极弱向心**：只受极小全局向心力，避免被拉拢堆叠
- 全局排斥力 225px 截止，确保近距离结点推开
- 全局最小间距约束保证结点不重叠

## 状态栏消息

状态栏统一颜色分类（定义在 `defines.hpp`）：

| 类型 | 颜色 | 场景 |
|------|------|------|
| 普通提醒 | 深灰 #1C1C1C | 文件操作、布局进度 |
| 成功/绿色 | 深绿 #15901A | 检查通过 |
| 错误/红色 | 深红 #C62828 | 检查失败、算法错误 |
| 进度/蓝色 | #5294E2 | 布局计算进度 |

## 标签页

- 每个标签页独立保存画布状态（缩放、位置）
- 切换标签页不丢失原标签页状态
- 拖拽标签按钮可调整顺序

## 右键菜单

- **右键结点**（已选中）：删除（删全部选中）/ 设为起点或取消 / 设为终点或取消 / 开始移动 / 追踪回图中心
- **右键边**（已选中）：删除（删全部选中）/ 编辑边权重 / 追踪回图中心
- **右键空白（有选中项）**：新增结点 / 删除选中 / 追踪回图中心
- **右键空白（无选中）**：新增结点 / 追踪回图中心

## 物理参数配置

菜单栏[物理]可打开物理参数对话框，调整运行时物理模拟参数：

| 参数 | 默认值 | 作用 |
|------|--------|------|
| K_REP | 3500.0 | 全局排斥力系数 |
| K_UNI | 0.06 | 单向边弹簧系数 |
| K_BI | 0.008 | 双向边弹簧系数 |
| G_UNIV | 25.0 | 万有引力/向心系数 |
| GAMMA_L | 0.15 | 布局阶段阻尼 |
| GAMMA_D | 0.45 | 维持阶段阻尼 |
| V_MAX | 2.0 | 速度上限 |
| IDEAL | 110.0 | 理想边长度 |
| MIN_DIST | 65.0 | 结点最小间距 |
| CUTOFF | 225.0 | 排斥力截止距离 |
